# P2287 3-3 栈的复杂应用：算术表达式

## 题目描述

栈在计算机的算术表达式解析和计算中有着重要应用。给定一个只包含个位数字、加号、减号、乘号以及左右括号的合法算术表达式，请编写程序计算该表达式的最终结果。计算时需遵循以下规则：

1. 括号具有最高优先级，需优先计算括号内的部分；
2. 乘法优先级高于加法和减法，需先计算乘法，再计算加减。

推荐做法：使用双栈（操作数栈 + 运算符栈）来求解，核心是：

- 遇到数字，压入数字栈；
- 遇到 `(`，压入运算符栈；
- 遇到 `)`，一直计算到栈顶为 `(`；
- 遇到运算符 `+ - *` 时，如果栈顶运算符优先级不低于当前运算符，就优先计算栈顶运算符，保证乘除优先、同级从左到右；
- 最后把运算符栈中剩余运算符全部计算完。

## 输入描述

输入为一行，包含一个字符串 S，表示待计算的表达式，字符串中不包含任何空格。字符串长度 L 满足 1 ≤ L ≤ 1000，字符串中仅包含字符 `0-9`, `+`, `-`, `(`, `)`。

计算全过程任何阶段的中间结果不会超出 int 的数据范围。

输入的表达式保证格式合法。

保证没有一元负号（例如 `-1+2`、`1*(-2)` 等情况）。

## 输出描述

输出一个整数，表示该表达式的计算结果。

## 样例输入

```
(3*(8-2)-(5-6*1))
```

## 样例输出

```
19
```

## 样例输入 2

```
2*3+4*5
```

## 样例输出 2

```
26
```

## 代码

```c
#include <stdio.h>

#define MAXSIZE 1005

int num[MAXSIZE];
int ntop = 0;           // 操作数栈，ntop == 0 为空
char op[MAXSIZE];
int otop = 0;           // 运算符栈，otop == 0 为空

// 优先级：乘 2，加减 1，左括号 0（遇到 ( 时不会被先算）
int priority(char c) {
    if (c == '*') return 2;
    if (c == '+' || c == '-') return 1;
    return 0;           // '('
}

// 弹出一个运算符和两个操作数，计算后把结果压回操作数栈
void calc() {
    char c = op[--otop];
    int b = num[--ntop];    // 后弹出的是右操作数
    int a = num[--ntop];    // 先弹出的是...注意这里 a 是左操作数
    int r;
    if (c == '+') r = a + b;
    else if (c == '-') r = a - b;
    else r = a * b;
    num[ntop++] = r;
}

int main() {
    char s[MAXSIZE];
    int i, len;
    scanf("%s", s);

    for (i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c >= '0' && c <= '9') {
            num[ntop++] = c - '0';
        }
        else if (c == '(') {
            op[otop++] = c;
        }
        else if (c == ')') {
            while (op[otop - 1] != '(') {
                calc();
            }
            otop--;                         // 弹出 '('
        }
        else {                              // + - *
            while (otop > 0 && priority(op[otop - 1]) >= priority(c)) {
                calc();
            }
            op[otop++] = c;
        }
    }

    while (otop > 0) {
        calc();
    }

    printf("%d\n", num[0]);
    return 0;
}
```
